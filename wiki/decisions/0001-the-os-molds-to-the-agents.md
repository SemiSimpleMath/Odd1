# The OS molds to the agents

Odd1 is an operating system for a person plus agents. Friction is removed for the agents so they can use their full
power and evolve the system quickly; when an agent struggles, the default fix is to change the OS, not to teach the
agent a workaround. Safety comes from undo, review and isolation (commits on branches, automatic rollback, backups,
a reviewer, agents on their own desktop and checkout), not from denying agents actions.

In the person's words: "This is an os for a Human + agents where all the friction is eliminated for the agents so
they can use their full power freely. the os molds to the agents not the other way aorund." and "We do want agents
to have freedom to rapidly evolve the system we only have few rules" (the four rules: 0002 to 0005).
