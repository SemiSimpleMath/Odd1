# Rule 2: the person's data is never destroyed

The person's data must never be destroyed, even by accident. It may be changed or deleted when the person wishes;
what the rule requires is that backups exist, so any accident can be recovered (odd1-backup: daily state, hourly
home; restores move things aside instead of deleting).

In the person's words: "2) users data must never be destroyed even by accident this does not mean users data can
never be altered or even deleted if they so wish, it just means backups have to exist so if there is an accident we
can recover."
