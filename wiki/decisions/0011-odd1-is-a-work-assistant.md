# Odd1 is a work assistant

Odd1 is a work assistant, not a personal assistant: no life-tracking features. The person's personal assistant, Emi,
is meant to run on top of Odd1 one day; what Emi needs is built as general Odd1 services (pods, tasks, the dojo,
secrets), not Emi-specific features.

In the person's words: "Odd1 does not intend to become users personal assistant. more like work assitant." and
"my dream is that Emi functions on top of Odd1."
